# HYBRID Maps Platform — Visual Identity & UX/UI Specification

Document ID: UX-01
Status: Official V1.0 visual baseline
Date: 2026-08-14
Reference asset: `Identidade Visual - Maps Platform.png` supplied by the project owner in Google Drive.

## Brand relationship

HYBRID Maps Platform is a HYBRID Tecnologia Inteligente product. Its identity is an extension of the HYBRID master brand, not an unrelated visual system.

## Official palette

- Deep background: `#0D1117`
- Dark graphite: `#1B2128`
- Neutral graphite: `#2E343B`
- HYBRID green: `#22C55E`
- Light neutral: `#F5F7FA`

Green communicates connectivity, growth and active/positive state. Dark tones communicate technology, trust, stability, precision and neutrality. Light neutral communicates clarity and simplicity.

## Typography

- Titles/highlights: Exo 2.
- Body/interface text: Inter.
- Fallbacks must preserve legibility and the technological, restrained character of the brand.

## Graphic language

Use fine topographic/contour lines, geolocation motifs, layers, connected nodes, security/data symbols and a restrained green path/accent. Graphics must remain subordinate to content and avoid visual noise.

## Iconography

Linear, minimal and consistent icons. Core semantic families: maps, layers, integration, data, cloud, security and analytics.

## Product UI

- Dark-first presentation for the reference Playground and branded product surfaces.
- Clear hierarchy, generous spacing and high contrast.
- HYBRID green reserved for primary action, active state and focal geospatial elements.
- Avoid gradients or unrelated colors that break the approved identity.
- Maps and geospatial overlays must not compromise controls/text contrast.

## Logo usage

Use approved principal, horizontal or icon version. Do not redraw, stretch, recolor outside approved monochrome/green treatment or combine with unrelated brand marks.

## Reference applications

The official identity defines application icon, splash screen, web interface, mobile reference, stationery/favicons and digital signature language. First-party HMP documentation and UI should remain visually consistent with those examples.
